# Water-Quality-Monitoring-System
Arduino Uno based water quality monitoring using a turbidity sensor and LCD display.

## Project Overview
This mini-project monitors water turbidity using an Arduino Uno and a turbidity sensor. An LCD displays the measured turbidity level, while output indicators help identify clear, cloudy, and dirty water conditions.

## Components Required
- Arduino Uno
- Turbidity Sensor
- 16x2 I2C LCD
- Buzzer and indicator components
- Breadboard and jumper wires

## Working Principle
1. The turbidity sensor measures the turbidity of the water sample.
2. Arduino Uno reads the sensor output.
3. The program maps the sensor reading to a turbidity value.
4. The LCD displays the value and the corresponding water clarity category.

## Applications
- Educational water-monitoring projects
- Demonstration of sensor-based monitoring
- Basic water clarity assessment

## Important Note
This project measures turbidity only. It does not establish whether water is safe for drinking.

## Technologies Used
Arduino Uno, turbidity sensor, I2C LCD, and Arduino programming.
